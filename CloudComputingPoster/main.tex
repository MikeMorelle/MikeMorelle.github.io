\newcommand{\textTaskFive}{
Auf dem Master-Node erfolgt die Installation von Prometheus und Grafana. Prometheus übernimmt dabei die Sammlung der Metriken, während Grafana deren Visualisierung ermöglicht. Auf jedem Worker-Node wird der Node Exporter installiert, der über Port 9100 Hardware- und Betriebssystemdaten bereitstellt. Im Anschluss an die Installation wird die Prometheus-Konfigurationsdatei unter /etc/prometheus/prometheus.yml um die IP-Adressen der Worker-Nodes sowie den Port 9100 ergänzt. Grafana ist anschließend über Port 3000 erreichbar, wobei Prometheus als Datenquelle unter localhost:9090 eingebunden wird. 
}
